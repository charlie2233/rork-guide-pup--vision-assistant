Data handling

How Guide Pup handles camera frames and anonymous device data.

This page reflects the current shipping behavior: frames are sent to the Guide Pup backend, may be processed by third-party AI providers, and are tied to anonymous session bootstrap state. Provider secrets stay server-side.

What is sent

Compressed camera frames, anonymous device/session bootstrap identifiers, and minimal request metadata.

Voice commands

Optional hands-free commands use the microphone and iOS speech recognition. Spoken commands are parsed into a bounded control set, and raw audio is not sent to AI providers by Guide Pup.

How outputs are used

Assistant responses are normalized and may safely degrade to STOP when confidence is low or hazards are unclear.

Crash reporting

Crash reporting is disabled in the current launch configuration. If enabled later, release diagnostics must stay scrubbed and aligned with App Privacy answers.

Current release note

If the final public privacy policy URL differs from this page, wire the release configuration to the new URL and keep the content aligned with the shipping app behavior.
